# 14. Plan de pruebas locales (propuesto; no ejecutado)

Ejecutar **después** de limpiar secretos y preparar un entorno aislado. Los comandos son ejemplos desde `Proyecto/`; sustituir muestras por datos consentidos y variables por `.env` local. No ejecutar migraciones ni POST sobre RDS de producción. Guardar logs sin tokens ni rostros/placas sin consentimiento.

Comandos de instalación futuros: `python -m venv ...`, `pip install -r` por módulo y `npm ci` deben correr **en copia limpia**, no sobre esta carpeta durante la auditoría. Antes de pruebas con mutaciones, congelar una base de prueba y plan de rollback. La batería `backend/tests/test_api.py`, `frontend/tests/*.test.js`, `pytest --collect-only` y `node --test` debe incorporarse a CI tras resolver fixtures y evitar servicios de producción.
