## Relación Edge comprobada

`smartpark_edge_production.py:261` importa `edge_server_demo_gpu_model_detection_v3.py`; este importa `smartpark_gate_cloud` como módulo de nivel superior (`:265`). El único archivo encontrado con ese nombre está en `smartpark_edge_installer/`, ignorado por Git y fuera del `sys.path` normal de la raíz: el comando desde fuente falla si no hay configuración externa de path/copia. El lanzador aplica configuración al núcleo (`:396-560`), inicia la API en un hilo y ejecuta `edge.gate.main()` (`:647-695`). Retira `/demo/trigger` de las rutas (`:569-589`). El instalador empaqueta otra copia `smartpark_edge_installer/smartpark_edge.py` mediante `SmartParkEdge_v2.spec` y `smartpark_launcher_release_v2.py`. No hay prueba de que el ejecutable actual se haya construido con el lanzador de fuente; deben compararse ambos caminos en una máquina limpia.

## Docker y Compose

`backend/Dockerfile`, `ai/Dockerfile` y `ocr/Dockerfile` tienen `CMD` para Uvicorn. El `docker-compose.yml` de raíz **solo** declara `db` (`postgres:17`, 5432) y `mqtt` (`eclipse-mosquitto:2`, 1883). No contiene los tres servicios HTTP ni Edge. El mount `./mosquitto/mosquitto.conf` coincide con la carpeta actual `mosquitto/`; `docker compose config --quiet` validó la configuración sin levantar servicios.

## Observación de alcance

`entradav2 (1).ino` apareció como archivo no seguido por Git durante la verificación final y fue inspeccionado sin mostrar credenciales. Define HC-SR04, SG90, Wi-Fi, MQTT/TLS, publicación `VEHICLE_DETECTED` y consumo OPEN/CLOSE. Importa `secrets.h`, que no está en el proyecto inspeccionado. Debe confirmarse que es el firmware final y que compila antes de declararlo canónico.
